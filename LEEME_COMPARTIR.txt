PDF2MD Batch Converter - instrucciones para compartir

1. Copia o descomprime esta carpeta completa en cualquier ubicacion del equipo.
2. Ejecuta iniciar_app.bat con doble clic.
3. Espera a que instale lo necesario la primera vez.
4. Cuando abra el navegador, usa la app en:
   http://localhost:5000

Importante:
- No cierres la ventana negra de CMD mientras estes usando la app.
- Para detener la app, vuelve a la ventana CMD y presiona Ctrl+C.
- La primera ejecucion puede tardar porque instala Python y dependencias.
- Si Windows pregunta permisos de red/firewall, permite el acceso local.
- Si quieres usar otro puerto, abre CMD en esta carpeta y ejecuta:
  iniciar_app.bat 8080

La app corre localmente en el computador. Los archivos PDF no se suben a internet.
