PDF2MD - instrucciones para compartir

1. Descarga el repositorio con Code > Download ZIP.
2. Descomprime la carpeta completa.
3. Ejecuta iniciar_app.bat con doble clic.
4. Espera a que instale Python y las dependencias en la primera ejecución.
5. Usa la aplicación en http://localhost:5000

La aplicación permite:
- PDF y Word a Markdown estándar.

No cierres la ventana de comandos mientras uses la aplicación. Para detenerla, presiona Ctrl+C.
Todo el procesamiento se realiza localmente; los documentos no se suben a internet.
